## Lancer le projet en local

Aucune dépendance à installer.

```bash
git clone https://github.com/paul23jj/portfolio.git
cd portfolio
```

Puis ouvre `index.html` dans ton navigateur, ou lance un petit serveur local :

```bash
npx serve .
# ou
python -m http.server 8000
```

## Déploiement

Le site est déployé automatiquement sur Vercel à chaque push sur la branche `main`.
